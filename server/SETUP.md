# Setup

## 1. Python

You need to have python installed, this is necessary to build the project.

## 2. Docker

You need to have docker installed, this is necessary to create the iamge and run the system.

## 3. Build the project

Copy all server files to the server and build using the dockerfile.

## 4. Store the keys

In the public keys folder which will be created, put all of the public keys you have, these must have the usernames of your users as their filenames.

## 5. Execute the server

Start the server and leave it running, when necessary stop the execution manually.
